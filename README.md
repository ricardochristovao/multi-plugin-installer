# WordPress Multi Plugin Installer

Um plugin WordPress que permite fazer upload e instalação de múltiplos plugins simultaneamente através de arquivos ZIP.

## 🚀 Funcionalidades

- Upload múltiplo de plugins em formato ZIP
- Instalação automática em lote
- Ativação automática após instalação
- Interface simples e integrada ao WordPress
- Feedback visual do processo de instalação
- Validação de arquivos ZIP

## 📦 Instalação

1. Faça o download do arquivo `multi-plugin-installer.php`
2. Faça upload para a pasta `wp-content/plugins/` do seu WordPress
3. Ative o plugin através do menu 'Plugins' no WordPress
4. Acesse através do menu Plugins > Upload Multiple

## 🛠️ Como Usar

1. Acesse o menu "Upload Multiple" no painel administrativo
2. Selecione múltiplos arquivos ZIP de plugins
3. Clique em "Instalar Plugins"
4. Aguarde o processo de instalação e ativação
5. Verifique o feedback de cada instalação

## 💻 Requisitos

- WordPress 5.0 ou superior
- PHP 7.2 ou superior
- Permissões de escrita no diretório de plugins
- Suporte a upload de arquivos ZIP

## 🔒 Segurança

- Verificação de nonce para todas as operações
- Validação de tipos de arquivo
- Verificação de permissões de usuário
- Limpeza automática de arquivos temporários
